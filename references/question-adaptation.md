# Question Adaptation

Rewrite every standard question with issuer, peers, market, and current reporting period.

## General rules

- Replace generic `这家` with the issuer's actual name.
- Replace placeholder peers `(A, B, C)` with the actual peer list.
- Split by segment when peer groups differ.
- Name the reporting window explicitly, for example `截至2026年一季度`.

## Market-specific rewrite rules

### A-share

Replace:

- `基石投资者是谁、认购金额、锁定期？`

With:

- `此次发行是否存在战略配售投资者？分别是谁、获配规模多少、限售期多久？是否包含产业资本、关键客户、关键供应商或具有定价指示意义的机构？`

### Hong Kong

Keep cornerstone wording:

- `基石投资者是谁、认购金额、锁定期多久？是否有知名产业资本、主权基金或长期资金背书？`

## Canonical rewrites

### 1. Core business

Rewrite to:

`请基于<issuer>的招股书和最新披露材料，说明公司的核心产品、核心业务线是什么；按业务线拆分近3年收入结构如何变化；前五大客户集中度如何变化，是否存在单一大客户依赖。`

### 2. Peer comparison

Rewrite to:

`请仅围绕<segment>业务，将<issuer>与<peer1>、<peer2>、<peer3>对比，说明毛利率、营收增速、研发费用率的主要差异，以及这些差异来自产品结构、价格周期、成本曲线还是客户结构。`

### 3. Cornerstone / strategic placement

Use the market rule above.

### 4. Proceeds and dilution

Rewrite to:

`请拆分<issuer>本次募资用途，各项目占比多少，最大募投项目是什么；发行完成后控股股东和实际控制人持股比例分别稀释到多少。`

### 5. Risks

Rewrite to:

`请把<issuer>招股书风险因素拆成两类：行业共性风险与公司特有风险，并说明哪些可以通过同行对照部分打折看，哪些必须单独警惕。`

### 6. Historical financing valuation

Rewrite to:

`请根据<issuer>历史融资、股权变化和招股书披露，估算上一轮重要融资估值与本次IPO估值的跳涨倍数；如果信息不足，请明确缺口。`

### 7. Earnings quality

Rewrite to:

`请检查<issuer>过去3年及最新一期利润中，是否存在政府补助、资产处置、公允价值变动、汇兑收益等一次性项目明显抬高利润；同时比较经营现金流净额与净利润是否匹配。`

### 8. Related-party exposure

Rewrite to:

`请说明<issuer>关联交易占营收和采购的比例，前五大客户与前五大供应商中是否存在关联方，是否存在交易公允性或独立性风险。`

## Final synthesis question

After the eight question families, ask:

`如果目标是判断是否参与<issuer>本次打新，请基于前述材料给出支持参与的3-5条核心理由、反对参与的3-5条核心理由，并按“参与 / 观察 / 放弃”给出结论。`
